## Quick Upload to GitHub & Vercel
1. Upload the files in this repository (`index.html`, `vercel.json`, `.gitignore`, `README.md`) to a new **GitHub** repository.
2. Go to [vercel.com/new](https://vercel.com/new) and import your GitHub repository.
3. Click **Deploy** — no build command or database setup is required for the static interactive bundle.
